⏰ Time-Based Display

Only shows during 5-7 PM. Automatically hides outside promo hours.

⏱️ Countdown Timer

Displays "Xh Ym left" and updates every 30 seconds.

❌ Dismissible

Close button persists dismissal in localStorage. Resets daily at 6 AM.

✨ Animations

Slide-down entrance, shimmer effect, pulsing dot, smooth transitions.

📱 Responsive

Adapts layout: horizontal desktop, stacked mobile with full-width button.

🎨 Theme Colors

Gold accent background with dark slate text. Matches website theme.

📍 Positioning

Location: Fixed below navbar
Z-Index: 40 (below navbar's 50, above content)
Trigger: Only during promo hours (5 PM - 7 PM)
Storage: localStorage for dismissal persistence

⚙️ Customization

Edit the promoConfig object in PromoBanner.tsx:
• message: Custom promotion message
• description: Details about the offer
• startTime: Hour to start (0-23)
• endTime: Hour to end
• ctaText: Button text
• ctaLink: Where button links to
